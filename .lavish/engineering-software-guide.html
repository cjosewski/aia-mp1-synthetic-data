Before an installation becomes a dependency

  1. Choose a concrete task and the application edition that supports it.
  2. Record the version, API/runtime and license entitlement.
  3. Run a small reproducible compatibility check before relying on automation.

This shortlist records recommendations, not purchase authorization, verified installations or a commitment to integrate every application. New tools do not change MP1’s frozen reference pack or review cohort.
